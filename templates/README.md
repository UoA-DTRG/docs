# Templates

This directory contains reusable templates for creating consistent documentation across the DTRG team.

## 📄 Available Templates

### Documentation Templates
- [Project Documentation Template](project-template/) - Complete project documentation structure
- [Guide Template](guide-template.md) - Template for writing guides and tutorials
- [Feature Documentation Template](feature-template.md) - Template for feature specifications
- [Meeting Notes Template](meeting-notes-template.md) - Template for recording meeting notes

### Quick Reference
- [Markdown Cheatsheet](markdown-cheatsheet.md) - Quick reference for markdown syntax

## 🎯 Using Templates

1. Copy the appropriate template for your documentation type
2. Fill in all required sections
3. Remove any sections that don't apply (mark as N/A if you want to keep the structure)
4. Follow the [documentation standards](../rules/documentation-standards.md)

## 📝 Template Guidelines

- Templates are starting points - adapt them to your needs
- Maintain consistent structure across similar documents
- Include all relevant information even if templates don't have a specific section
- Update templates as team needs evolve
