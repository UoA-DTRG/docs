## 📝 Documenting a New Feature

When implementing a new feature, create documentation that includes:

1. **Overview** - What the feature does and why it exists
2. **Requirements** - Functional and non-functional requirements
3. **Architecture** - How the feature is designed and integrated
4. **Implementation** - Key implementation details and code structure
5. **API** - Endpoints, parameters, and examples (if applicable)
6. **Testing** - Test coverage and testing approach
7. **Usage** - How to use the feature with examples
8. **Known Issues** - Current limitations or known bugs

Use the [feature documentation template](../templates/feature-template.md) to get started.
